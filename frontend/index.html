Serverless Image Processing Pipeline

Upload an image. S3 → SQS → Lambda → Step Functions produce a thumbnail, a display rendition and a watermarked copy, served back over CloudFront.

Pipeline

  • Requesting a pre-signed URL from API Gateway
  • Uploading directly to the S3 source bucket
  • S3 event queued in SQS, workflow started
  • Step Functions: validate → resize → watermark
  • Metadata written to DynamoDB, results on CloudFront
